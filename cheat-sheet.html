Pattern cheat sheet

The whole book on one page: every pattern with the problem it solves, when to skip it, and the tool that fills the slot. Use it to recognise what you are looking at in any AI product, and as a checklist when you design your own.

Seven rules

Rule
1Write ten test cases before the first prompt. Measure before you improve.
2When an answer is wrong, look at what was retrieved before you blame the model.
3Exact work (sums, comparisons, lookups, queries) belongs in code. The model gets the finished fact.
4Try the cheapest fix first: prompt, then context, then structure, then a bigger model, then finetuning.
5Prefer a workflow. Use an agent only for the step that cannot be planned.
6Treat model output as untrusted input. Security lives in code and permissions, not in the prompt.
7One run is a sample. Add a box only when a failing case asks for it.

When something is wrong, look here

SymptomLikely causeFirst thing to try
A confident answer that is not in your documentsNothing relevant was retrieved, and no way out was given.Print the retrieved chunks; add "say you don't know".
The right document exists but is never foundVocabulary mismatch, or bad chunking.Add the other kind of search; check how the document was split.
Found, but the answer ignores itToo many chunks, or the best one is buried in the middle.Rerank; send fewer; put the best nearest the question.
A wrong number or comparisonThe model did arithmetic.Compute it in code and pass the result.
Output that will not parseFormat only requested in prose.Structured output with a schema, validated.
Different answers to the same questionSampling, or the provider changed something.Temperature 0; pin the version; rerun the evals several times.
SlowLong outputs, or several model calls in a row.Shorter answers, streaming, a smaller model, fewer calls.
ExpensiveLong prompts on every call, or a large model everywhere.Fewer chunks, a small model per step, caching.
It did something it should not haveA tool allowed it.Narrow the tool's permissions; add a confirmation.
